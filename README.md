# PIXEL Master — المرحلة 1

هذا مشروع **Next.js حقيقي** (ليس Demo) — الأساس التقني الكامل جاهز، وبقية الأجزاء تُبنى فوقه في مراحل قادمة.

## ما تم بناؤه في هذه المرحلة ✅

- **قاعدة البيانات الكاملة** (`prisma/schema.prisma`): كل الكيانات المطلوبة —
  المستخدمين، التصنيفات، الخدمات، الوسائط، الأعمال، الباقات، طرق الدفع،
  الطلبات، إعدادات الموقع. **لا يوجد أي سعر أو نص ثابت في الكود.**
- **نظام تسجيل دخول حقيقي** (NextAuth + bcrypt): كلمات المرور محفوظة كـ hash،
  الجلسات آمنة، ولوحة `/admin` محمية بالكامل عبر Middleware.
- **الصفحة الرئيسية**: Hero بهوية Electric Blue / Dark Premium، قسم الخدمات،
  وقسم "أحدث أعمالنا" — الثلاثة يقرؤون مباشرة من قاعدة البيانات، فأي تعديل
  تُجريه من لوحة الإدارة (في المرحلة القادمة) يظهر تلقائياً بدون لمس الكود.
- **الهوية البصرية**: نظام تصميم كامل (ألوان، خطوط، حركة) في
  `tailwind.config.ts` و`globals.css`.

## المراحل القادمة 🔜

1. لوحة الإدارة (`/admin`) + إدارة الأعمال والوسائط (رفع Drag & Drop حقيقي).
2. صفحة "أعمالنا" مع الفلاتر والبحث.
3. نظام الطلب الكامل + طرق الدفع اليدوية + رفع إثبات الدفع.
4. حساب العميل ومتابعة الطلبات.
5. لوحة إحصائيات المدير + الإشعارات.

## كيف تشغّله فعلياً (بدون خبرة تقنية) 🚀

1. **قاعدة بيانات مجانية**: أنشئ حساباً على [Neon](https://neon.tech) أو
   [Supabase](https://supabase.com)، وانسخ رابط `DATABASE_URL`.
2. **استضافة**: أنشئ حساباً على [Vercel](https://vercel.com)، واربطه بمستودع
   الكود (GitHub).
3. ضع المتغيرات من `.env.example` في إعدادات المشروع على Vercel (Environment
   Variables) — عبّئ `DATABASE_URL` و`NEXTAUTH_SECRET` على الأقل.
